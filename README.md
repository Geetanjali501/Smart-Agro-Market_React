A full-stack agricultural marketplace web application designed to connect farmers directly with buyers and consumers, eliminating middlemen and ensuring fair, transparent pricing.
• Direct Farmer-to-Buyer Marketplace: Farmers can list fresh produce with pricing,quantity and availability details.
• Product Search & Filtering: Buyers can browse and filter agricultural products by category,price and availability.
• User Authentication & Role Management: Secure registration and login workflows for farmers and buyers.
• Order & Cart Management: End-to-end cart handling and order tracking for seamless transactions.
• Responsive Design: Clean,mobile-friendly interface built for accessibility across devices.
**Tech Stack**
• Frontend: React.js, HTML5, CSS3, JavaScript
• Backend: Node.js, Express.js
• Database: MongoDB
• Version Control: Git & GitHub
